## About

I'm a software engineer based in Mexico. I've been building and learning in public on GitHub since 2018, with interests spanning backend development, cloud infrastructure, automation, and application security.

I enjoy understanding systems from the ground up: designing APIs, writing maintainable code, automating infrastructure with code, and building practical tools to solve real problems. I also use hands-on labs and side projects to deepen my knowledge of software architecture, distributed systems, and cloud technologies.

**What I focus on**
- **Software engineering:** API design, backend development, software architecture, and test-driven development.
- **Cloud & DevOps:** AWS, infrastructure as code, containers, and automation.
- **Security:** API discovery, reconnaissance, networking, and security tooling.
- **Continuous learning:** Algorithms, system design, Python, and Elixir.
